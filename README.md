### 🚦 CCTV Traffic Accident Detection & Prediction — *Graduation Project*
An AI system that analyzes CCTV feeds to detect accidents in real time, predict risky situations before a collision happens, and send alerts to a government dashboard.

## 🤝 Team Projects

### 🧠 [Brain Tumor MRI Classification](https://github.com/Gerges1245/brain-tumor-classification)
Trains the same CNN on three versions of an MRI dataset (Raw, Preprocessed, Cleaned) to measure how image processing affects accuracy. Preprocessing and denoising (bilateral filter, contrast enhancement, unsharp masking) were implemented from scratch in NumPy.
- **Result:** the cleaned pipeline reached **80.3% accuracy** and **0.945 ROC-AUC**, vs 74.0% and 0.912 on raw images
- **Tech:** Python, TensorFlow/Keras, OpenCV, scikit-learn

### 🫀 [Heart Disease Prediction](https://github.com/Gerges1245/heart-disease-prediction)
A machine learning system that predicts heart disease risk from lifestyle and medical survey data (300K+ records) using EDA, feature engineering, SMOTE balancing, and a stacking ensemble.
- **Models:** Logistic Regression, Random Forest, XGBoost, LightGBM, HistGradientBoosting + Stacking Ensemble (AUC **0.835**)
- **Tech:** Python, scikit-learn, XGBoost, LightGBM, imbalanced-learn

### 💻 [AI Laptop Recommender System](https://github.com/Gerges1245/laptop-recommender-system)
A Flask web app that recommends laptops from natural-language queries in **Arabic and English**, with intent detection (gaming, ML, video editing, ...), a TensorFlow embedding recommender, and an EDA dashboard.
- **Tech:** Python, Flask, TensorFlow, scikit-learn, NLP, Chart.js

### 🧩 [Maze Search Algorithms Visualizer](https://github.com/Gerges1245/maze-search-algorithms)
An interactive maze solver that visualizes BFS, DFS, and A* (with multiple heuristics) step by step, with a random maze generator and a stats panel.
- **Tech:** Python, Tkinter

### 🏨 [C++ Hotel Booking System](https://github.com/Gerges1245/cpp-hotel-booking-system)
A console-based hotel management system with guest registration, room booking, admin operations, and file persistence, built with OOP and custom linked lists.
- **Tech:** C++, OOP, Data Structures, File I/O
